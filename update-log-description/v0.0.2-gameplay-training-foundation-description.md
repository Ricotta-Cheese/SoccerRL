# v0.0.2 Gameplay Training Foundation

This milestone starts the measurement layer needed before reward shaping or
training code. The goal is to compare simple scripted baselines, identify obvious
rule and physics issues, and keep future tuning numeric instead of purely
subjective.

## Added Baseline Policies

The first scripted policies live in `soccer_rl/policies.py`:

- `random`: uniformly samples all actions
- `chase`: moves toward the ball and kicks when close
- `safe_chase`: chases the ball but targets the outside edge of forbidden goal
  areas and backs away from unsafe next moves
- `defensive`: chases in the defensive half and otherwise guards a home-side lane

These policies intentionally use observations rather than direct environment
state, so they are closer to the interface later learning agents will see.

## Added Evaluation Runners

Single matchup runner:

```bash
python scripts/evaluate_agents.py --left chase --right random --episodes 20 --seed 1
```

All-vs-all matrix runner:

```bash
python scripts/compare_baselines.py --episodes 50 --seed 1
```

The metrics include wins, truncations, goals per episode, average episode length,
average rewards, out-of-bounds counts, goal-area violations, and ball
relocations.

## Early Observations

- `chase` creates goals, but it also enters the forbidden goal area often.
- `defensive` is much safer around goal areas but rarely creates scoring chances.
- Random-vs-random almost always truncates, so goals are not happening by chance.
- Ball relocations mainly happen when both policies contest the ball directly,
  which gives a useful signal for stuck-ball tuning.

## Safe Chase Variant

`safe_chase` was added as a goal-area-aware version of `chase`. It keeps the
naive chase baseline intact, but changes the target when the ball is inside a
forbidden goal area and overrides unsafe next moves before they step into a goal
area box.

Safe chase tradeoff:

- Against `random`, right-side `safe_chase` scored 12 goals with 0 own goal-area
  violations, compared with `chase` scoring 17 goals with 100 own violations.
- Left-side `safe_chase` vs `random` scored 9 goals with 0 own goal-area
  violations, compared with `chase` scoring 17 goals with 105 own violations.
- A few goal-area violations can still appear in mixed matchups, likely from
  collisions, contest resolution, or velocity state rather than direct target
  choice.
- `safe_chase` is a better candidate for later reward-shaping comparisons, while
  `chase` remains useful as a deliberately naive pressure baseline.

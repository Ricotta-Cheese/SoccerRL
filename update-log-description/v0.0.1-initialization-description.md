# v0.0.1 Initialization Description

This document summarizes the initial SoccerRL setup on branch:

```text
RA_v0.0.1-initialization
```

## Goal

The first milestone is a small, debuggable 1v1 soccer sandbox that can be run
before any learning code is added. The current target behavior is:

```bash
python scripts/play_random.py
```

This opens a Pygame field, moves two random agents, scores goals, and resets the
episode after a goal.

## Environment Setup

The project uses Python 3.13.13 in a local `.venv`.

Python 3.14 was avoided because `pygame` attempted a source build on macOS and
failed due to missing SDL headers. Python 3.13 installs `pygame==2.6.1` from a
prebuilt wheel, which keeps setup simple.

Dependencies are listed in `requirements.txt`:

- `numpy`
- `pygame`
- `gymnasium`
- `pettingzoo`
- `pytest`
- `matplotlib`
- `tqdm`

## Current Environment Behavior

`Soccer1v1Env` is a PettingZoo-style `ParallelEnv` with two agents:

- `left`
- `right`

Available actions:

```text
0 stay
1 up
2 down
3 left
4 right
5 kick
```

The environment currently supports:

- reset and step flow
- sparse rewards
- goal detection
- score tracking
- episode termination after a goal
- random-agent play
- manual keyboard control for the left player
- Pygame rendering
- headless `rgb_array` rendering for tests

## UI and Rendering

The renderer includes:

- green soccer field with subtle stripes
- center line and center circle
- team-colored players
- team-colored goals
- compact scoreboard using matching team colors
- simple goal notification badge

Controls for manual play:

```text
WASD or arrow keys: move the left player
Space: kick
Escape, Ctrl+C, or window close: stop
```

## Physics and Tuning

Most tuning values live as module-level constants near the top of
`soccer_rl/envs/soccer_1v1.py`.

The current constants cover:

- field size and goal width
- player speed and player radius
- ball radius
- kick speed
- possession radius
- kick radius
- ball friction
- ball rolling resistance
- ball stop speed
- wall bounce
- render size
- team colors

Ball movement now has simple inertia plus slowdown:

- `BALL_FRICTION` applies proportional drag each frame.
- `BALL_ROLLING_RESISTANCE` subtracts steady speed while the ball rolls.
- `BALL_STOP_SPEED` snaps the ball to rest when it gets slow enough.

This keeps the ball from traveling too far after a kick while preserving a small
inertia feel.

## Validation

Current validation commands:

```bash

```

```bash
python -m py_compile scripts/play_random.py scripts/play_manual.py soccer_rl/envs/soccer_1v1.py
```

The test suite currently checks:

- default constants feed environment attributes
- reset returns both agents and valid observations
- step output has the expected parallel-env shape
- goal rewards and terminations are correct
- kicked ball has inertia but stops within a short range
- rendered goals use the correct team colors
